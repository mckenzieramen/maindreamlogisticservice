# MAINDREAM LOGISTIC SERVICES

Static premium fleet/logistics management website.

## Deploy
- Put `index.html` at the repository root.
- Cloudflare Pages: production branch `main`.
- Build command: blank.
- Build output directory: `.`

## Data
This V1 stores demo/entered records in browser localStorage. It includes:
Dashboard, Trips & Deliveries, Trucks, Employees, Payroll, Expenses, Loans, Maintenance & Documents, Clients, Invoices, Payments, Reports and Settings.

## Important
This is the working front-end foundation. The exact original XLSX was not available in the retrieved source set during generation, so accounting formulas are based on the documented requirements available in the project notes and are intentionally record-driven rather than hard-coded.
